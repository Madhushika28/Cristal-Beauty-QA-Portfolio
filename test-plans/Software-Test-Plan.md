
# Software Test Plan

## Project Information

**Project Name:** Cristal Beauty Clean — E-Commerce System  
**Test Project:** Software Quality Assurance Portfolio  
**Test Type:** Manual, API and Automated Testing  
**Status:** Planning  
**Version:** 1.0

## 1. Introduction

This document outlines the planned quality assurance activities for the Cristal Beauty Clean E-Commerce System.

The purpose of testing is to evaluate whether the application's implemented features satisfy their expected functional requirements and to identify defects that may affect reliability, usability and security.

## 2. Testing Objectives

- Verify core application functionality.
- Validate user authentication and authorization.
- Evaluate product browsing and management.
- Verify shopping cart and order workflows.
- Test API response behavior.
- Identify and document software defects.
- Develop automated regression tests.
- Record test results and supporting evidence.

## 3. Scope of Testing

### In Scope

- User Registration and Login
- Product Browsing and Search
- Shopping Cart
- Checkout and Orders
- Role-Based Access Control
- API Validation
- User Interface Testing

### Out of Scope (Initial Phase)

- Production load testing
- Real-money payment transactions
- Third-party infrastructure penetration testing

## 4. Testing Approach

### Manual Testing
Functional test cases will be designed and executed against the application.

### API Testing
Postman will be used to validate selected backend API endpoints.

### Automation Testing
Playwright will be used to automate selected critical user workflows.

### Defect Tracking
Identified defects will be documented with reproduction steps, expected results, actual results and supporting evidence.

| Tool | Purpose |

## 6. Entry Criteria

- Required application components are available.
- Test environment is configured.
- Relevant requirements are identified.
- Required test data is prepared.

## 7. Exit Criteria

- Planned test cases have been executed.
- Test results are documented.
- Identified defects are recorded.
- Critical defects are reviewed.
- Test summary report is prepared.

## 8. Deliverables

- Software Test Plan
- Manual Test Cases
- API Test Collection
- Automated Test Scripts
- Bug Reports
- Test Execution Evidence
- Test Summary Report
